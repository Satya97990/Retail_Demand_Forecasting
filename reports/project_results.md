# Retail Demand Forecasting — Validation Results

These results were generated by the included pipeline from `data/raw/train.csv` on the project's packaged run. The forecasting model was evaluated on a time-based holdout, and the whole 90-day horizon was predicted recursively.

## Dataset profile

- Training rows: 913,000
- Test rows: 45,000
- Training dates: 2013-01-01 to 2017-12-31
- Test dates: 2018-01-01 to 2018-03-31
- Stores: 10
- Items: 50
- Store/item series: 500
- Validation dates: 2017-10-03 to 2017-12-31 (90 dates)

## Validation metrics

| Metric | HistGradientBoostingRegressor | Seasonal-naive baseline |
|---|---:|---:|
| MAE | 6.1241 | 11.6487 |
| RMSE | 7.9435 | 15.4132 |
| WAPE | 11.2099% | 21.3224% |
| sMAPE | 12.9017% | 22.2704% |
| Bias (prediction minus actual) | +0.2269 | +6.1643 |

The model is better on these metrics for this specific 90-day historical holdout. This is not a claim about the hidden competition test labels or about future performance at Lowe's. The included test file has no actual sales targets, so no test-set accuracy can be calculated from the supplied files.

## Important caveats

- Sales is used as a proxy for demand; stockout observations are not identified.
- The data has no product price, inventory, promotions, weather, holiday, or supply lead-time variables.
- PSI drift bands are heuristics used for screening, not proof that model accuracy has declined.
